# Shade

A beginner-friendly game where a boy can jump between dimensions. Inspired by Geometry Dash and Limbo.

✨ Technologies
- JavaScript
- Canvas API / Game Engine
- HTML/CSS

🚀 Features
Dimension-jumping gameplay:
- Jump between light and shadow dimensions
- Platform navigation with physics
- Obstacle avoidance
- Progressive difficulty levels

🛠️ The Process
This game focuses on:

- Creating a game loop with Canvas.
- Implementing player movement and jumping mechanics.
- Managing dimension/state transitions.
- Detecting collisions.
- Rendering game elements and animations.

▶️ Running the Project
1) Clone the repository
```
git clone https://github.com/K2222810/Shade.git
cd Shade
```

2) Install dependencies (if applicable)
```
npm install
```

3) Open the game
```
Open index.html in your browser or use a local server
```

Open: http://localhost:3000 (or your local server)
